# Cineblast VFE — version Qt

## Lancer
- Double-clic : `Lancer Cineblast VFE (Qt).bat`
- Debug (console) : `Lancer Cineblast VFE (Qt) - debug.bat`

## Fichiers
- Config : `VFE_Config.json` (schéma compatible avec l’ancienne app)
- Journal : `VFE_Log.txt` (lignes de la version Qt préfixées `[Qt]`)
- Frames noires de la session : `%TEMP%\vfe_black_frames` (purgé à chaque extraction)

## Raccourcis
- Flèches : navigation dans la sélection
- Ctrl+A : tout sélectionner · Échap : désélectionner
- Suppr / Retour arrière : supprimer la sélection (corbeille)
- Touche de marquage (défaut `S`) : marquer / démarquer la sélection

- Archivée dans `archive_tkinter\` (lançable depuis ce dossier, avec sa propre copie de la config).
- Prototypes de migration dans `archive_prototypes\`.
