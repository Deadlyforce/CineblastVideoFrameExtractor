## 1. Ambiance générale

Choix possible :

- A — Cinéma pro : sobre, graphite, très neutre, outil de montage / étalonnage.
- B — Studio cyan : moderne, technique, accent cyan/bleu désaturé.
- C — Darkroom : plus chaud, accent ambre/orange discret, ambiance salle obscure.
- D — Creator tool : plus clair visuellement, mais toujours sombre, style outil YouTube moderne.
- E — Autre chose à préciser.

Réponse : C


Commentaire : -


---

## 2. Couleur d’accent

Objectif : une seule couleur principale pour les actions importantes, la sélection, les éléments actifs.

Choix possible :

- Cyan désaturé
- Bleu froid
- Ambre / orange doux
- Rouge cinéma très discret
- Violet / magenta très discret
- Autre

Réponse : Ambre / orange doux


Commentaire : -


---

## 3. Niveau de densité

Objectif : définir si l’interface doit être plus compacte ou plus aérée.

Choix possible :

- Compact : beaucoup d’infos visibles, style outil pro dense.
- Normal : équilibre entre densité et respiration.
- Aéré : plus d’espace, moins de texte visible, plus confortable.

Réponse : Normal


Commentaire : nous irons peut-être vers un mix entre compact et normal (à voir au fur et à mesure)


---

## 4. Forme des composants

Objectif : définir l’arrondi général.

Choix possible :

- Très carré : radius 2 à 4 px.
- Légèrement arrondi : radius 6 px.
- Moderne standard : radius 8 à 10 px.
- Très arrondi : radius 12 px ou plus.

Réponse : Légèrement arrondi


Commentaire : à confirmer après les remières visualisations concrètes


---

## 5. Style des icônes

Objectif : remplacer les emojis par de vraies icônes.

Choix possible :

- Line fine, très sobre
- Line arrondie, plus douce
- Duotone légère, plus moderne
- Icônes pleines, plus visibles
- Autre

Réponse : Icônes pleines, plus visibles


Commentaire : -

## 7. Ce que tu ne veux PAS

Très important pour éviter les fausses directions.

Exemples :

- pas d’emojis ;
- pas de bleu trop saturé ;
- pas de fond noir pur ;
- pas de style trop gamer ;
- pas de glassmorphism ;
- pas trop de sombras / effets ;
- pas d’interface trop claire ;
- autre.

Réponse : pas d’emojis, pas de fond noir pur, pas de style trop gamer, pas de glassmorphism, pas d’interface trop claire, pas trop de sombras / effets
